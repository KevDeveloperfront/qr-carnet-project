# QR Carnet Generator


Aplicación web para generar carnets digitales con códigos QR.


## 🚀 Funcionalidades
- Creación de fichas personales
- Generación de QR único
- Visualización optimizada para móviles
- Panel administrativo simple


## 🧰 Tecnologías
- Node.js
- Express.js
- SQLite
- EJS
- TailwindCSS
- QRCode.js
- PM2
- Nginx


## 📦 Instalación rápida


```bash
npm install
pm2 start server.js --name qr-backend
